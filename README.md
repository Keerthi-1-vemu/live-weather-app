#Live weather App
A simple and powerful web app to check  **real-time weather** of any city in the world using open weather API.
Built with Python+Streamlit
## FEATURES
Search any city-Hydrabad, Dublin, London......
Shows live temperature ,feels like, humidity
Shows weather condition-Clear,Clouds, Rain, etc
Error handling for invalid city names
##TECH STACK
python
streamlit
OpenWeather API
Requests
